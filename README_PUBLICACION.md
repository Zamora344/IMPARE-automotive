# IMPARE STUDIO v1.3

**Estado:** prototipo interno para revisión. No es una tienda operativa ni una publicación oficial de marca.

## Diseño
- Cinco secciones reales con páginas HTML individuales; navegación mediante enlaces convencionales.
- Fotografía editorial (recorte intencional) distinta de fotografía de producto (sin recortes).
- Collection BMW-first: filtros por generación F/G y por Interior/Exterior/Performance.
- Galería real de volante y consola facilitada por Edgard.
- Proyectos: dos G20 de concepto, sin atribuirlos a trabajos reales.
- ATELIER: video corto con salida CSS de cinco segundos y opción Omitir; formulario de cita demostrativo, sin envío ni almacenamiento.
- Paleta Obsidiana, Marfil, Titanio cálido.

## Publicación de prueba
1. Extraer el ZIP.
2. Abrir `index.html` en Chrome/Edge para revisión local.
3. Para una URL HTTPS, subir el contenido de esta carpeta (o ZIP) a un alojamiento de sitios estáticos, como Netlify Drop o Cloudflare Pages.
4. **Importante:** una URL temporal suele ser pública por defecto; activar protección de acceso antes de compartir fotos, textos o información privada.

## Antes del lanzamiento
Validar marca IMPARE, licencias de imágenes, autenticidad y compatibilidad, políticas comerciales, inventario, backend de formularios, privacidad, disponibilidad y seguridad.

## Material gráfico
Se reutilizan los recursos de la v1.2. Las fotos del volante y consola provienen de Edgard; el resto son ilustrativas, no representaciones de artículos en venta ni de vehículos reales de la empresa.
